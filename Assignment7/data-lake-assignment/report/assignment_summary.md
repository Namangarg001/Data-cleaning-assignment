# Week 7 Assignment Summary

## Assignment Title

Delta Lake MERGE Implementation

---

## Objective

Perform incremental data processing using Delta Lake by loading data into a Delta Table, creating incremental data, applying MERGE operations, and validating the results.

---

## Tasks Performed

- Loaded Superstore Dataset
- Explored Dataset
- Checked Null Values
- Removed Duplicate Records
- Handled Missing Values
- Renamed Columns
- Converted Numeric Columns
- Created Delta Table
- Created Incremental Dataset
- Applied Delta MERGE Operation
- Validated Row Count
- Checked Duplicate Customer IDs
- Displayed Final Dataset

---

## Result

The MERGE operation successfully updated existing records and inserted new records into the Delta Table.

The final dataset was validated successfully.

---

## Conclusion

This assignment demonstrated how Delta Lake supports efficient incremental data processing using MERGE operations for handling new and updated records.
